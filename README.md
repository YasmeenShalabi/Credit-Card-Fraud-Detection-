# Credit Card Fraud Detection

This project demonstrates a basic end-to-end machine learning classification workflow for detecting fraudulent credit card transactions.

The dataset is processed with Pandas, split into training and testing sets, and used to train a Random Forest Classifier with Scikit-learn. Model performance is evaluated using accuracy, precision, recall, F1-score, and a confusion matrix.

## Tech Stack

- Python
  
- Pandas
  
- Scikit-learn

## ML Workflow

Data Loading → Preprocessing → Train/Test Split → Model Training → Prediction → Evaluation
